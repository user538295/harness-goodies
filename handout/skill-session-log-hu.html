Mi ez

A /session-log az aktuális környezet által átadott prompt- és válaszszöveget helyi Markdown-átiratba írja. Pontosan öt környezetet támogat: Claude Code, Codex, Cursor, OpenCode és OMP.

Mindegyikben ugyanaz a négy parancs használható, de a riportok szándékosan nem egyformák. Az adapterek kizárólag a környezet saját életciklus- és usage-adataiból dolgoznak: a Cursor a fordulónkénti tokenszámokat a hookok adataiban adja át, az átiratokban nem; a Codex a natív rollout rekordokból ad tokenösszeget.

Mit kapsz

  • Olvasható session-átirat. A natív életciklus-eseményekből elérhető promptok, végleges válaszok és alügynök-jelzések időrendben kerülnek egy privát, helyi Markdown-fájlba.
  • Valós natív usage-adatok. A Claude Code és az OMP fordulónkénti adatokat is tud adni; az OpenCode a fő session és az alügynökök natív összesítéseit írja ki; a Codex egy rollout-TOTAL-t ad. A Cursor a stop hook által rögzített tokenszámokból ad TOTAL-t, csak a fő ügynökre.
  • Idő- és költségadat csak ott, ahol létezik. A Claude Code offline árbecslést számol; az OpenCode és az OMP megőrzi a natív költségmezőket. A Codex és a Cursor tokenmezőket ad ár és munkaidő nélkül.
  • Natív alügynök-elszámolás, ahol elérhető. A Claude Code, az OpenCode és az OMP a saját tárolójában elérhető alügynök-rekordokat is figyelembe veszi. A mezők és a csoportosítás környezetenként eltérnek.
  • Egyértelmű környezetazonosítás. Az univerzális skill az aktuális hostot/modellt kéri meg, hogy válassza ki a claude, codex, cursor, opencode vagy omp azonosítót; útvonalból, folyamatból vagy környezeti változóból soha nem találgat.
  • Helyi és privát. A kezelt naplófájlok 600 jogosultságúak, és a csomag semmit nem tölt fel.

A négy parancs

A /session-log-ot ezek egyikével futtatod. Argumentum nélkül a status az alapértelmezett.

ParancsMit csinálJellemző kimenet
on Telepíti az aktuális környezet adapterét, majd bekapcsolja a naplózást. <címke>: on vagy on — restart required; Codexnél on — trust review/restart required
off Kikapcsolja a naplózást az aktuális környezetben. <címke>: off
status alapértelmezett Szükség esetén helyreállítja a bekapcsolt adaptert, majd kiírja az állapotot. on / off / on — adapter missing / on — restart required; Codexnél on — trust review/restart required
usage Az aktuális környezet natív usage-riportját futtatja. <címke>: usage és natív riport

A pontos címkék: Claude Code, Codex, Cursor, OpenCode és OMP. A usage alapból a legújabb natív sessiont választja; megadhatsz sessionazonosítót, illetve ahol az adapter elfogadja, átirat-útvonalat. Az OpenCode csak azonosítót vagy --latest-et fogad el. A --check kizárólag Claude Code alatt használható, és a telepített ccusage eredményével vet össze.

Jó tudni

  • Telepítsd mind az ötöt bekapcsolás nélkül. A repó gyökerében futtasd ezt: bash install-universal-session-log.sh. A parancs minden alapértelmezett skill-gyökérben létrehozza vagy frissíti a teljes stabil csomagot, és az OpenCode parancs-belépési pontját is telepíti.
  • Egy környezetet parancsfuttatás közben is előkészíthetsz. Például a bash skills/session-log/install.sh --harness cursor --arguments "status" előbb létrehozza vagy frissíti a Cursor csomagját, majd lefuttatja a status parancsot. A --install --harness <azonosító> csak telepít, parancsot nem futtat.
  • Az aktiválás környezetenként külön történik. Az on, az off és a status csak a megadott azonosítót érinti. Az on — restart required után indítsd újra a környezetet. Codexnél nézd át és engedélyezd a ~/.codex/hooks.json-hoz adott parancsokat, majd indítsd újra.
  • A bekapcsolt adapter helyreáll magától. Az installer minden parancs előtt frissíti a kiválasztott stabil csomagot. Bekapcsolt naplózásnál a status és a usage a hiányzó vagy elavult natív adaptert is újratelepíti.
  • A usage nem közös séma. A Claude Code fordulónkénti és alügynök-összesítést ad offline árbecsléssel; az OpenCode és az OMP a natív token- és költségadatokat őrzi meg; a Codex ár nélkül összegzi a rollout tokenrekordjait; a Cursor pedig összegzi azokat a tokenszámokat, amelyeket a stop hook bekapcsolt naplózás mellett, az aktuális adapterrel rögzített — csak a fő ügynökre, mert a subagentStop nem ad tokenadatot —, és egyértelmű hibával leáll, ha egy sessionhöz nincs rekord.
  • A függőségek parancsonként eltérnek. A csomag előkészítéséhez bash, Python 3 és shasum vagy sha256sum kell; a futásállapot ellenőrzéséhez és a Claude Code-hoz jq szükséges. Az OpenCode usage ezenfelül sqlite3-at, az OMP riportja pedig Bunt igényel. A ccusage csak a Claude Code --check opcionális függősége.
  • Csak az alapértelmezett gyökerek támogatottak. Ezek: ~/.claude, ~/.codex, ~/.cursor, ~/.config/opencode (a natív adatok helye ~/.local/share/opencode) és ~/.omp/agent. Az áthelyezett gyökerek egyértelmű hibával leállnak.

Hogy néz ki egy naplózott forduló

Helyzet: egy teljes forduló — elküldesz egy promptot, egy háttér-al-ügynök befejeződik, az asszisztens válaszol, és az előző forduló óta modellt és effortot váltottál. Ez kerül a session-fájlba (Claude Code, ~/.claude/prompt-logs/<projekt>/session_….md):

## 14:02:11

Implement the next uncompleted task in plans/FEAT-001.md

---

14:03:05 sub-agent finished: general-purpose (agent-9f3c2a1b), jsonl: /Users/…/<sid>/subagents/agent-9f3c2a1b.jsonl

### 14:05:53 response

<az asszisztens végleges üzenete, szó szerint>

working time: 00:03:42
est. used token: input: 2000, output: 1000, cache_create: 150000, cache_read: 0, total_tokens: 153000, price: $2.32, model: claude-opus-5, effort: max
switched: model claude-sonnet-5 → claude-opus-5, effort high → max

---

Fentről lefelé olvasva: a prompt, majd a lefutott al-ügynök, majd a válasz, majd a mérések. A total_tokens = input + output + cache-írás + cache-olvasás. Az itteni switched: sor magyarázza a nagy cache_create-et: a modellváltás teljes cache-írást kényszerített ebben a fordulóban.

Ilyen a Claude Code usage riportja

Parancs: /session-log usage Claude Code alatt (az aktuális projekt legújabb sessionjét összesíti). A többi környezet megtartja a fent leírt saját riportformáját.

Claude Code: usage

1. 14:02:11  Implement the next uncompleted task…   est. used token: … price: $2.32
2. 14:12:40  Fix the failing test in auth_test…      est. used token: … price: $0.41
   sub-agent general-purpose (agent-9f3c2a1b)         est. used token: … price: $0.77

TOTAL (2 requests, 1 sub-agent)  input: … output: … total_tokens: …  price: $3.50

Fordulónként egy számozott sor, al-ügynökönként egy sor a sessionben talált átiratokból, majd egy összevont TOTAL. Minden átirat egyszer számít, bármilyen mélyen ágyazódnak az al-ügynökök.
